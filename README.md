I build language-model systems and tools for developers. I'm the founder of [EverestQ](https://www.everestqai.com/) and a B.Tech Computer Science student at **SRMIST**, graduating in **2027**.

My public work spans agent evaluation, language runtimes, and computer vision. I'm interested in how models use tools, how we measure their failures, and how to turn experiments into useful software.

[Portfolio](https://www.rahulchaube1.com/) · [LinkedIn](https://www.linkedin.com/in/rahulchaube1/) · [All repositories](https://github.com/Rahulchaube1?tab=repositories)
