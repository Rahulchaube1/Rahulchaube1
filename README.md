I build open-source software at the intersection of **AI, systems programming, and interactive tools**. My interests range from language compilers to agent evaluation and spatial interfaces.

I care about what the code actually does: clear behavior, reproducible experiments, and honest documentation of what is still in progress.

## What draws me in

**AI that can be inspected.** Evidence-grounded agents, evaluation tools, and traces that make behavior easier to understand.

**Systems that explain themselves.** Language design, compiler internals, and developer tools with clear boundaries.

**Interfaces worth using.** Interactive graphics, spatial workflows, and applications that make complex ideas tangible.
