<summary>About my work</summary>

I build open-source software at the intersection of AI, systems programming, and interactive tools. My interests include language models, agent evaluation, compiler design, and the foundations of more general intelligence.

- **[Blyx](https://github.com/Rahulchaube1/blyxxxx)** — an experimental language for AI-oriented systems programming.
- **[GuardedDesk](https://github.com/Rahulchaube1/GuardedDesk)** — an agent evaluation prototype with synthetic scenarios and audit traces.
- **[AR Studio](https://github.com/Rahulchaube1/AR)** — browser-based drawing and 3D creation with hand tracking.
- **[MapNepal](https://github.com/Rahulchaube1/mapnepal)** — terrain, landmarks, and trekking routes.

I care about clear behavior, reproducible experiments, and honest documentation of work in progress.
